## 范围

同一匿名用户通过聊天明确保存稳定偏好/交互纠正/采购背景/业务引用，并在新会话按需读取、查询、纠正或删除。

## 验收标准

- [ ] 四类与显式来源持久记录，用户之间隔离，有效显式内容不自动过期
- [ ] 新会话使用相关有效内容；当前明确需求优先于旧偏好；本次例外不改长期保存
- [ ] 聊天查询、纠正、删除有真实结果，删除不影响订单、消息或清单
- [ ] 不把临时人数/预算默认存成长期画像，不新增管理页或重复任务状态
- [ ] 引用重新查询业务来源，不让记忆替代价格库存或授权
- [ ] 记录单票 Git 基线，红/绿与必要回归证据，本票提交、双轴审查与有效修复；不得推送。
