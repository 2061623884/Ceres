## 范围

浏览或聊天提出可乐需求后按结构化条件展示有限真实候选和关键差异，用户调整并选定，进入现有清单及明确确认加购。

## 验收标准

- [ ] 品牌/每件容量/罐瓶/整包内件数/整包售价条件分别生效
- [ ] 卡片显示整包总量/件数/售价和每升价格，最多五候选，事实来自已核资料
- [ ] 气泡及自然语言修改条件刷新候选，选定绑定真实 SKU，不提前建购买授权
- [ ] 无匹配说明且原清单购物车不变；选定后清单改选确认到cart一致
- [ ] 首页或品类上下文沿用已有入口；不新增比较面板
- [ ] 记录单票 Git 基线，红/绿与必要回归证据，本票提交、双轴审查与有效修复；不得推送。
