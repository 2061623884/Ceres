## 范围

正常聊天完成后在回复链路外自动提取稳定信息，并由显式配置的轻量模型低频整理自动内容，长期显式保存保持有效。

## 验收标准

- [ ] 自动来源30天有效期，临时条件不误提取，不覆盖冲突显式内容
- [ ] 回复不等待自动模型，后台错误有原因记录且不吞错或自动回退
- [ ] 达到10条有效自动内容且距整理>=24h触发，Dream去重/过期清理，不删除有效显式内容
- [ ] 召回最多5条/2000字，不以召回上限丢弃保存内容；用户主动查询可见有效列表
- [ ] 保存真实 MEMORY_MODEL配置和样本；模型不可用标阻塞，mock不冒充真实验收
- [ ] 记录单票 Git 基线，红/绿与必要回归证据，本票提交、双轴审查与有效修复；不得推送。

## 测试边界

公开聊天结果和记忆读取行为，外部模型/时钟边界可控；隔离后台事务；真实轻量模型采样及原回复速度检查另记录，由 tester执行。
所有测试命令委派专职tester，环境隔离；tester只运行报告，不改源码/测试/文档/TASK/Git。
