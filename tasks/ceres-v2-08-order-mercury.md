规格：[实施规格](../docs/plans/ceres-v2-spec.md)

## 范围

现有独立购物车模拟结算生成本用户的持久订单，进入墨墨后用订单胶囊/订单ID气泡选择这一单并查询事实，沿用明确售后请求边界。

## 验收标准

- [x] 结算持久订单及SKU/名称/数量/成交价快照与购物车一致，原cart清空有一致结果
- [x] 刷新及新会话查询同一订单，其他owner不能读，不回退固定演示用户
- [x] 订单胶囊列表和聊天选项绑定订单ID，墨墨每次咨询一个选定订单
- [x] 选单/查询不申请退款退货，明确诉求按现有业务语义执行并留结果
- [x] 初始化不破坏现有活动数据，不复制第二份商品目录，不自动跳转角色
- [x] 记录单票 Git 基线，红/绿与必要回归证据，本票提交、双轴审查与有效修复；不得推送。

## 测试边界

所有测试命令委派专职tester，环境隔离；tester只运行报告，不改源码/测试/文档/TASK/Git。
