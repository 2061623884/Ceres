## 验收标准

- [ ] 最终同版固定核心用例全部通过、关键违规为零，新增模块相关完整回归及 Standards/Spec 最终审查完成，有效问题修复后定向复验。
- [ ] 常规路由新增 P95 ≤1 秒；完整回复检验 ≤15 秒目标，冷启动、失败、超时与样本量单列。未满足不得标技术全部通过或放宽既定目标。
- [ ] 独立中文案例分类型报告误切换、漏切换、澄清和失败，源版本与实际调用一致，不重新开展模型采用 A/B 选型。
- [ ] 交付模型启动/停止及实际调用说明、两角色 SSE/切换结果约定、打开周期与主动切换语义、最小 demo 和复核步骤；不自动部署到正式站点。
- [ ] Cursor 接入后的实际页面验证单列，覆盖同意/拒绝、双向、主动恢复、政策、一次打开额度及新周期；未接入时明确记录缺失条件，不能用静态页面替代。
- [ ] 用户本人确认体验前状态保持待验收；源/数据/模型/Prompt/用例与页面适用版本可追溯。
