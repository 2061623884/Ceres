# Ceres v1 04：采购一致性与单菜流程

- 状态：待开始

- 依赖：[03 响应可靠性](ceres-v1-03-response-latency.md)

## 范围与顺序

沿用现有匿名身份、会话状态、plan-revisions 和确认接口。先验证 required 默认勾选、pantry 默认未选；改选后的金额、版本、刷新恢复、后端确认及购物车新增一致，明确确认前不加购。通过后再验证单菜推荐／点名、预算、食材排除、换或撤回、逐道追加及关系澄清；不实现人数或菜间搭配优化。

缺必需食材时先展示可售部分与缺项，保留旧清单／购物车；用户明确选可售部分后才建部分待确认清单，并保留缺项说明，单独明确确认后才加购。预算及排除条件继续生效。追加保留旧分组，同 SKU 按分组贡献汇总；未明确追加／替换关系时先澄清，不实现多组局部原子替换。

## 验收、下一步与证据

相关公共 API／受控回归及必要实际链路核对通过，普通 ACK／预览／关系未定均不授权加购。已有正确路径优先验证，只修复实际缺口；正式同版两次统一放 06，旧采购与语义 TASK 不自动验收。
