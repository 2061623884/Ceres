- [x] 18 个固定核心业务场景及其关键断言全部通过；未经同意切换、错用订单、重复处理、重复提示和无来源政策等关键违规为零。

- [x] 建立开发/回归/留出分组，公开核心案例不冒充留出；同一场景改写不跨开发与独立验证集，预期依据明确。
- [x] 单列受控 API、真实 Kev 与角色主模型采样，记录路由准确情况、误切换/漏切换/澄清、业务结果和原始错误。
