# 01 单菜人数到采购与确认

状态：进行中
负责人：主 Agent；测试命令由专职测试子 Agent执行。
规格：[实施规格](../docs/plans/ceres-v2-spec.md)
依赖：继承输入基线已记录；与其他业务票独立。

## 范围

用户指定并修改一道菜人数，得到来源可核的食材需求、完整包装购买量和剩余，完成改选及明确确认后的购物车一致性。

## 验收标准

- [ ] 4人番茄炒蛋：番茄需求600g、2包500g；鸡蛋6枚、1包6枚
- [ ] g/ml线性换算，枚数小数按规格定义向上取整；展示需求、购量和剩余
- [ ] 必需默认勾选、pantry默认不勾选；人数改变后版本与金额一致
- [ ] 未确认不加购，确认后 SKU/包数/金额一致；预算和排除不放宽
- [ ] 记录单票 Git 基线，红/绿与必要回归证据，本票提交、双轴审查与有效修复；不得推送。
