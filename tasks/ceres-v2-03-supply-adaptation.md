## 范围

## 验收标准

- [x] 其他同食材规格可售且足量时依据实际总价和近价剩余选购，差异可见
- [x] 可售数量不足及整种无供给均明确缺项和受影响菜品，不换其他食材
- [x] 首次供给预览不改清单/购物车；明确选可售部分后建部分清单，单独确认
- [x] 库存/预算/排除与金额重核；原商品目录不因模拟缺货被删除
- [x] 记录单票 Git 基线，红/绿与必要回归证据，本票提交、双轴审查与有效修复；不得推送。
