## 范围

对代表性菜品构造独立 Offer 缺货场景，在约束内选同食材其他规格或多包装；无法凑齐时展示缺项并让用户明确决定部分采购再确认。

## 验收标准

- [ ] 其他同食材规格可售且足量时依据实际总价和近价剩余选购，差异可见
- [ ] 可售数量不足及整种无供给均明确缺项和受影响菜品，不换其他食材
- [ ] 首次供给预览不改清单/购物车；明确选可售部分后建部分清单，单独确认
- [ ] 库存/预算/排除与金额重核；原商品目录不因模拟缺货被删除
- [ ] 记录单票 Git 基线，红/绿与必要回归证据，本票提交、双轴审查与有效修复；不得推送。
