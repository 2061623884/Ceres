## 验收标准

- [ ] 同一候选覆盖零食/饮品分类与筛选、四类能力及 workflow、售后后继续采购、主页专题成品选购。
- [ ] 新增预定行为与必要既有回归通过，关键授权、订单、步骤重放和事实违规为零；不得以无关旧任务结论替代本批验收。
- [ ] 受控业务、真实 Kev 与角色主模型、实际页面点击及人工表达审读分别记录；不足或不可达明确保留未验证项。
- [ ] 新留出按场景冻结并仅在候选冻结后执行；失败如实保留，不调参后冒充同一留出独立成功。
- [ ] 已有能力有 V3 整体对照，路由/Prompt 有固定变量的阶段对照；商品数据变化不混入收益归因。
- [ ] 记录调用、Token 可得性、阶段/完整耗时、样本量与冷启动条件，结果摘要直接链接原始证据。
- [ ] 总结用户问题、产品闭环、架构取舍、测评结果与限制；未经本人接受不写已验收。
